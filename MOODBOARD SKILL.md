# Creating Professional Mood Boards

## Objective

To facilitate the creation of professional mood boards by selecting visual references from platforms such as Dribbble, Behance, Pinterest, and Awwwards. This helps align the client’s expectations with the final design outcome, ensuring it is approved before design work begins.

## When to Use

- At the start of a design project to establish a clear visual direction.
- When the client has difficulty expressing their visual preferences.
- To seek inspiration from design styles they are not familiar with.
- When presenting creative direction options and requesting client approval.
- Before starting work in design tools like Figma.

## How to use

1. Copy the following message into an AI tool like Claude or ChatGPT.
2. Describe the project, the audience, and the client’s visual preferences.
3. Receive a search script and a suggested structure for the mood board.
4. Curate references on the specified platforms.
5. Assemble the mood board in a tool like Figma or Milanote.

## Practical Examples

### Example 1: Fintech Landing Page Redesign

**Input:**
- Project: Redesign of landing page and sales materials for a B2B SaaS fintech company.
- Adjectives: Modern, trustworthy, tech-forward, premium, dark.
- Don’ts: Generic, overly colorful, childish, and corporate.
- References: Lineal, Stripe, Vercel.

**Output:**
- **Dribbble:** Search terms like "dark fintech dashboard," "dark SaaS homepage theme."
- **Filters:** Black/dark color, grid layout.
- **Key references:** Linear (clean, dark user interface), Stripe (subtle gradients, typographic hierarchy), Vercel (grid, spacing, developer aesthetic).

### Example 2: Visual Identity for a Specialty Coffee Roastery

**Input:**
- Project: Single-page site for a boutique Dhaka roastery selling dated, single-origin
  bags to home brewers. The brand's claim is that every bag shows its roast date. No
  photography is available at launch, so the design must work on typography alone.
- Adjectives: Precise, warm, documentary, quietly premium.
- Don'ts: Rustic chalkboard café clichés, latte-art stock photography, script "artisanal"
  serifs, dark-green-and-gold luxury, coffee-bean illustrations.
- References: Coffee Collective, Onibus, Tim Wendelboe.

**Output:**
- **Dribbble:** Search for "editorial coffee packaging," "monospace label system,"
  "type-driven landing page."
- **Pinterest:** Search for "roast log layout," "batch ticket design," "coffee bag label
  typography."
- **Filters:** Paper/neutral palette, typographic, sans-serif, no photography.
- **Anchor references:** Coffee Collective (product as hero, one call to action),
  Onibus (ranked lists, hairline rules), Tim Wendelboe (restraint, no decoration).
- **Design consequence:** because there is no imagery, the proof has to *become* the
  design — dates, lot numbers and producer names rendered as the visual language.

A worked example for this repository is in `MOODBOARD.md`.

## Expected Output

The expected result is a well-structured mood board that includes a selection of 8–12 focused visual references, each with a clear justification for its inclusion. The mood board should be organized by categories such as mood, color palette, typography, and design. This will serve as a visual guide for the final design, ensuring that the client’s expectations are aligned from the start.
